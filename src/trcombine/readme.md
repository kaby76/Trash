# trcombine

## Summary

Combine a split ANTLR4 parser and lexer grammar into one grammar.

## Usage

```sh
dotnet trash parse tests/trcombine/Gold/ArithmeticParser.g4 tests/trcombine/Gold/ArithmeticLexer.g4 \
  | dotnet trash combine \
  | dotnet trash text
```

`combine` reads a PAX/tar parse-result bundle from stdin, or from `-f FILE`.
It requires exactly one parser grammar and one lexer grammar, in either order.
The parser's `tokenVocab`, when present, must name the supplied lexer grammar.
The output is a PAX/tar bundle containing one `<name>.g4.pt` parse result and
an empty `<name>.g4.errors` file. Source `.g4` files on disk are not changed.

The [XQuery4 transformation](combine.xq) changes `parser grammar` to `grammar`,
removes the `Parser` suffix from the grammar name, removes the parser's
`tokenVocab` option (or its entire options block if that was the only option),
and appends every lexer rule after the parser rules. Other parser options are
retained. The command removes the input parser and lexer `.pt`, `.errors`, and
`.g4` members from the output bundle; unrelated artifacts are passed through.

To extract the combined source into a directory:

```sh
dotnet trash parse tests/trcombine/Gold/ArithmeticParser.g4 tests/trcombine/Gold/ArithmeticLexer.g4 \
  | dotnet trash combine \
  | dotnet trash text --bundle \
  | dotnet trash sponge -c -o combined
```

ANTLR4 combined grammars cannot contain lexer modes. Grammars with target-specific
actions, lexer-only options, or incompatible parser/lexer prequels may need manual
adjustment before the combined grammar can be generated by ANTLR.

Run the regression cases with `bash tests/trcombine/test.sh` from the repository
root after building `trparse`, `trcombine`, and `trtext` in Release configuration.
