# trnullable

## Summary

Input Antlr grammars and print which rules are nullable.

## Description

Reads a parsing result set for a grammar and outputs the rules that are nullable.

## Usage

    dotnet trash nullable

## Examples

    dotnet trash parse A.g4 | dotnet trash nullable

## Current version

Release 2.7.0.
